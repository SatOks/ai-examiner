# ШІ-екзаменатор з NLP

Лабораторна робота 9 з курсу «Основи великих мовних моделей» (НУ «Львівська політехніка»).

LLM-агент, який проводить усний іспит у чаті: питає ім'я та email, отримує 2–3 випадкові теми,
по кожній ставить кілька запитань, а наприкінці показує оцінку 0–10 з відгуком і записує результат.
Модель `openai/gpt-oss-120b` через Groq API сама вирішує, коли викликати інструменти.

## Інструменти агента

| Інструмент | Що робить |
|---|---|
| `start_exam(email, name)` | Шукає студента в `data/students.json`, записує початок іспиту, повертає 2–3 випадкові теми. Якщо студента немає або ім'я не збігається, повертає помилку, і агент перепитує дані. |
| `get_next_topic()` | Повертає наступну тему і ключові пункти повної відповіді з `data/topics.json` (за ними агент ставить запитання й оцінює). Порожня тема означає кінець іспиту. |
| `end_exam(email, score, history)` | Записує оцінку і повну історію чату в `data/results/`. Модель передає `email`, `score` і текст відгуку; відгук спершу показується студенту, а `history` агент додає сам. |

Історія для `end_exam` у форматі з завдання: `{"role": "system" | "user" | "tool_call", "content": ..., "datetime": ...}`,
де `system` означає репліки екзаменатора, `user` студента, а `tool_call` виклик інструмента з аргументами й результатом.

## Як це влаштовано

- `exam_tools.py`: функції іспиту і «база даних» на JSON-файлах. Перевіряє аргументи в коді:
  не можна завершити іспит, поки не пройдено всі теми, оцінка лише 0..10.
- `agent.py`: системний промпт, JSON-схеми інструментів і цикл агента: модель → виклик інструмента →
  результат → модель, доки модель не відповість студенту текстом (не більше 8 кроків на репліку).
  Якщо основна модель вичерпала ліміт токенів Groq, хід продовжує запасна (`qwen/qwen3.8-27b`,
  `openai/gpt-oss-20b`), а якщо обмежені всі, агент чекає стільки, скільки просить Groq.
- `streamlit_app.py`: чат на Streamlit. Ключ Groq вводиться в бічній панелі і ніде не зберігається.
- `simulate.py`: прогін повних іспитів, де студента грає інша LLM (сильний, слабкий, «маніпулятор»).
- `test_*.py`: тести функцій і циклу агента з підставною моделлю (`python -m pytest -q`).

## Локальний запуск

```bash
pip install -r requirements.txt
streamlit run streamlit_app.py
```

Потрібен API-ключ Groq: безкоштовно на [console.groq.com](https://console.groq.com/keys).
Для перевірки можна скласти іспит як `Демо Студент`, `demo@lpnu.ua`.
